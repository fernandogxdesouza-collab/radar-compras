Radar de Compras

Como conectar este painel (uma vez, neste aparelho)
Para pesquisar e editar a lista daqui, o painel precisa de um token do GitHub só para este repositório, com a permissão de rodar workflows. Ele fica guardado apenas neste navegador.
  1. Abra github.com/settings/personal-access-tokens/new.
  2. Nome: radar-compras. Validade: 1 ano. Repository access: Only select repositories, escolha radar-compras.
  3. Em Permissions, Repository permissions, ponha Actions: Read and write. Nada mais.
  4. Gere o token, copie e cole abaixo.
Sem token, os botões abrem a página do GitHub onde você roda o comando à mão.
